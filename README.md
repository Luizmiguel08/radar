# Radar de Comissões · app

App do Radar de Comissões da Fortal Inteligência Imobiliária: comissões, recebimentos, cobranças e repasses, com avisos no celular.

Aqui fica só o código das telas. Os dados ficam no banco do app e só abrem com o código da equipe ou com o PIN de cada corretor.

Endereço: https://luizmiguel08.github.io/radar/
